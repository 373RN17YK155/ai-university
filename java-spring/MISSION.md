# Mission: Java, Kotlin и Spring Boot

## Why
Через 1–2 месяца (ориентир — начало 2027) я начинаю работать в продакшен-микросервисе на Spring Boot 3,
где код поровну на Java 17 и Kotlin. С первых недель нужно уверенно читать чужой код, вносить
изменения и добавлять новые фичи, не блокируя команду.

## Success looks like
- Открываю незнакомый Spring Boot сервис и за час объясняю, как запрос проходит от контроллера до базы и обратно.
- Добавляю REST-эндпоинт по схеме «OpenAPI-спецификация → сгенерированный интерфейс (openapi-generator) → контроллер → сервис → репозиторий».
- Пишу и правлю код и на Java, и на Kotlin в одном проекте, понимаю, как они взаимодействуют.
- Работаю с PostgreSQL через Spring Data JPA и jOOQ, пишу миграцию Liquibase.
- Вызываю соседний сервис через Feign; отправляю и читаю сообщение Kafka.
- Пишу `@Scheduled`-задачу и метрику для Prometheus.
- Покрываю фичу тестами: JUnit, Testcontainers (Postgres, Kafka), WireMock для внешних HTTP.
- Собираю проект Maven'ом и прохожу Checkstyle.

## Constraints
- На Java не писал. Основной язык — TypeScript: объяснения строим на сравнении с ним.
- Срок 1–2 месяца до старта, 4–6 часов в неделю (≈20–45 часов всего).
- Kotlin на равных с Java.

## Out of scope
- SQL как самостоятельный навык (запросы, индексы, EXPLAIN) — предмет `sql/`.
- Docker, Kubernetes, Helm, CI/CD — предмет `infra/`.
- WebFlux и реактивщина, Spring Cloud сверх Feign, Elasticsearch, Redis (в рабочем сервисе не используются).
- JasperReports/iText — позже, если понадобится по задачам.
