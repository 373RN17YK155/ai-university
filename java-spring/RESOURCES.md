# Java, Kotlin & Spring Resources

## Knowledge

- [dev.java — Learn Java (Oracle)](https://dev.java/learn/getting-started/)
  Official Java tutorials, current language. Use for: language basics, first programs, modern features.
- [Java Language Specification, SE 17](https://docs.oracle.com/javase/specs/jls/se17/html/index.html)
  The normative definition of the language. Use for: settling exactly what the language does.
- [JEP 330: Launch Single-File Source-Code Programs](https://openjdk.org/jeps/330)
  Run `java Hello.java` without a separate compile step. Use for: early lessons before Maven.
- [JEP 395: Records](https://openjdk.org/jeps/395)
  Immutable data carriers in Java 16+. Use for: DTOs, value types.
- [Kotlin docs](https://kotlinlang.org/docs/home.html) · [Calling Java from Kotlin](https://kotlinlang.org/docs/java-interop.html)
  Official language reference and Java interop. Use for: every Kotlin lesson; mixed Java/Kotlin code.
- [Spring Boot reference](https://docs.spring.io/spring-boot/index.html)
  Official reference for Spring Boot 3. Use for: auto-configuration, properties, profiles, actuator.
- [Spring Guides](https://spring.io/guides)
  Short official step-by-step guides. Use for: hands-on steps (REST service, JPA, scheduling).
- [Spring for Apache Kafka reference](https://docs.spring.io/spring-kafka/reference/)
  Use for: `KafkaTemplate`, `@KafkaListener`, error handling.
- [OpenAPI Generator: spring generator](https://openapi-generator.tech/docs/generators/spring/)
  Options of the generator the work service uses. Use for: API-first lessons.
- [Testcontainers for Java](https://java.testcontainers.org/)
  Use for: integration tests against real Postgres/Kafka.
