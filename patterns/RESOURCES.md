- [Repo: tshemsedinov/Patterns-JavaScript](https://github.com/tshemsedinov/Patterns-JavaScript)
  Freshest map of patterns for JavaScript, Node.js and TypeScript by Timur Shemsedinov; links out to example repos. Use for: the curriculum's backbone and code examples.
- [Repo: tshemsedinov/Patterns-by-Examples](https://github.com/tshemsedinov/Patterns-by-Examples)
  Patterns shown through platform-native JS/Node.js/async examples. Use for: a second, concrete example when the first isn't enough.
- [Repo: tshemsedinov/Patterns-Interview-Questions](https://github.com/tshemsedinov/Patterns-Interview-Questions)
  Interview questions on SOLID, GoF, GRASP, DI, DDD. Use for: quizzes, recall pads and self-checks.
